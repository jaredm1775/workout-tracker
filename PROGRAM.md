# Size PPL × Strength Upper/Lower (5 days)

This is Jared's program. It's a 5-day hybrid in the style of Jacob Oestreicher's PPL × Upper/Lower, and each muscle is trained twice a week. The two halves of the week have different jobs:

- **Push / Pull / Legs build size.** Moderate weight, 8–15 reps, and every working set goes to failure.
- **Upper / Lower build strength.** Heavy compound lifts for 3–6 reps, stopping 1–2 reps short of failure.

Each session has one lift per movement pattern, with the biggest lift first. Sessions take about 40–55 minutes. Log every working set in the app. The rest timer starts when you mark a set done.

This is general training guidance, not medical advice. Skip or substitute anything that hurts a joint.

## Weekly layout

| Day | Session | Goal | Focus |
|---|---|---|---|

| 2 | Pull | Size | Back & biceps |
| 3 | Legs | Size | Quads |
| 4 | Rest | | |
| 5 | Upper | Strength | Bench, pull-up, row |
| 6 | Lower | Strength | Squat & hinge |
| 7 | Rest | | |

The app's "Next" chip is always the day after your most recently finished session, in the order Push → Pull → Legs → Upper → Lower (then back to Push). If you skip ahead and do Upper, Next becomes Lower. Take your rest days after Legs and after Lower.

## Size vs. strength at a glance

| | Size days (Push, Pull, Legs) | Strength days (Upper, Lower) |
|---|---|---|
| Reps | 8–12 compounds, 10–15 isolation | 3–6 main lifts, 6–10 accessories |
| Effort | Technical failure | RPE 8–9 (1–2 reps left) on main lifts |
| Sets | 2 (set 2 is a back-off) | 3 straight sets at the same weight |
| Rest | 1:15–2:30 | 3:00–3:30 on main lifts |
| Progression | Top set (first set hits the top of the range) | All sets (every set hits the top of the range) |

**First week on this layout:** the app's "Next" weight still comes from your old 5–9 rep sessions. On size days, drop about 10–15% so you land in the new range. On strength days, start a little heavier than your old 5–9 weight.

## Size days: how hard (technical failure)

1. **What failure means.** It's the last rep you can finish with full range of motion and the same form. If a rep slows to a grind and barely makes it, that was the last one. Stop once the next rep would need body English, a shortened range or a spotter.
2. **Warm up first, then go all-out.**
   - Before the first exercise for each muscle, do 2–3 ramp-up sets: about 50% × 8, 70% × 5 and 85% × 2–3.
   - For later exercises on a muscle that's already warm, one feeler set is enough (about 60% × 5).
   - Don't log warm-ups. The first set you log is the all-out top set.
3. **Set 2 is a back-off set.** Keep the same weight and expect 1–3 fewer reps. If that would drop you below the rep range, take off about 10%. Set 2 also goes to failure.
4. **Calibrate.** Stop when you think you have 1 rep left, then try it. If it goes up cleanly, you weren't at failure. Most people underestimate how far they are from failure by 2–4 reps.

## Strength days: how hard (RPE 8–9)

1. **Ramp up more.** Before the first lift, work up in 4–5 sets: bar × 8, 50% × 5, 70% × 3, 80% × 2, 90% × 1. Don't log these.
2. **Three straight sets** at the same weight. Stop each one with 1–2 clean reps left. Rest the full 3:00–3:30.
3. **Progression:** once all 3 sets reach 6 reps, add the increment next session.
4. **Accessories** on strength days (shoulder press, leg curls, arms, calves) use the size rules: to failure, top-set progression.
5. **Safety.** Barbell bench, squat, RDL and overhead press always use safeties or a spotter. Never grind through joint pain.

## Typical increments

- **+5 lb** on presses, rows and pull-ups
- **+10 lb** on squats, hack squat and hinges
- **+2.5 lb** on small cable and dumbbell work

## No Smith machine or rack?

Tap **Swap** on the exercise:
- **Presses:** a machine press, or dumbbells you can drop.
- **Squats:** Smith squat or belt squat on strength days; leg press or pendulum on size days.

## Deload

After each 8-week block, or whenever your joints feel beat up, take a deload week: 1 set per exercise. Size lifts stop about 2 reps short of failure (2 RIR), and strength lifts use about 80% of their working weight. Then go back to the normal sets.

## Block rotation

Train in 8-week blocks with a deload week between them. Each new block changes some accessories and keeps the main strength lifts. Change lifts only at the start of a block, never mid-block, since progress comes from repeating a lift week to week.

| Weeks | Block |
|---|---|
| 1–8 | **Block 1:** the program as written above |
| 9 | Deload |
| 10–17 | **Block 2:** swaps below |
| 18 | Deload |
| 19–26 | **Block 3:** back to Block 1 lifts. Your history picks up where you left off. |

Then keep alternating Block 1 and Block 2.

**Rules**
- Bench, weighted pull-up, T-bar row, back squat and RDL never rotate.
- If an accessory is still going up every week or two, keep it for another block. Rotate the ones that have stalled or bother a joint.
- Each swapped-in lift starts with no history. The first session in a new block, pick a weight you can do for the middle of the rep range, and the app will progress it from there.

**How to switch in the app:** on the first session of a block, tap **Swap** on each lift in the table and pick the new one. The swap sticks every session after that. At the next block, swap back to the original.

## How to use the app

1. Pick today's day, or the suggested "Next" day.
2. Enter the weight and reps, then tap **Done** on each set.
3. The rest timer starts on its own. Use −15 / +15 or Skip. Your actual rest time is saved on the next set.
4. **Swap** (on exercises that have alternatives) changes the lift, and it sticks: next session starts with whatever you logged last time. Swap back to the original to return to it. Each alternative keeps its own history and "Next" weight. Swapping locks once you've logged a set for that exercise.
5. **+ Note** opens a small note on the exercise, for things like seat height or a one-off machine. Next session it shows up as "Last note". Notes appear in History and sync to the Sheet.
6. **+ Set / − Set** under an exercise adds a set for today or removes one you haven't logged. It doesn't change the program.
7. Tap **Finish** when the session is done.
8. Use Calendar to see which days you trained this week and this month.
9. Export JSON from Backup if you want a copy. That file is private unless you put it in the public repo.
