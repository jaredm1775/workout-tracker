# Commercial Gym Push / Pull / Legs

Intermediate physique program for a full commercial gym. Run it **6 days** (Push A, Pull A, Legs A, Push B, Pull B, Legs B) or **5 days** by skipping Legs B.

Sessions should take about 60–75 minutes. Log every working set in the app. The rest timer starts when you mark a set done.

This is general training guidance, not medical advice. Skip or substitute anything that hurts a joint.

## Effort and progression

- Work at about **1–2 RIR** on strength and muscle work. Finish the set with 1–2 clean reps still possible.
- Use **double progression**: when every working set hits the top of the rep range at the target RIR, add the smallest practical plate and return to the bottom of the range.
- Typical jumps: **+5 lb** on upper-body compounds, **+10 lb** on squats and hinges, **+2.5 lb** on isolation.
- After week 1, the app’s “Next” weight is the last working load, or that load plus the increment if you earned it.
- Do not chase gym-max singles. Milestone checkboxes are working-set goals.

## Weekly layout

| Day | Focus |
|---|---|
| Push A | Chest |
| Pull A | Vertical / width |
| Legs A | Squat |
| Push B | Shoulders / triceps |
| Pull B | Thickness |
| Legs B | Hinge / unilateral (skip on a 5-day week) |

Leave a rest day wherever it fits. Two days in a row of the same pattern (for example Push A then Push B) is fine. Avoid three brutal lower-body days in a row.

## Deload

Every fifth week, or whenever joints feel beat up: do 2 working sets instead of 3–4, keep the load, and stay around 3 RIR. Then return to the normal set counts.

## How to use the app

1. Pick Today’s day or the suggested “next” day.
2. Enter weight and reps. Tap **Done** on each set.
3. The rest timer starts automatically. Use −15 / +15 or Skip. Actual rest is stored on the next set.
4. Tap **Finish** when the session is done.
5. Check milestone goals when you actually hit them.
6. Export JSON from Backup if you want a copy for Cursor. That file is private unless you put it in the public repo.
